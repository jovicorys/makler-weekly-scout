# 🏠 Makler Weekly Scout

Automatischer Crawler für Immobilien-Angebote von lokalen Maklern.

## Dashboard
👉 **https://jovicorys.github.io/makler-weekly-scout**

## Manuell starten
1. Gehe auf GitHub → Repository → **Actions** Tab
2. Klicke auf **"Makler Weekly Crawler"**
3. Klicke **"Run workflow"** → **"Run workflow"**

## Automatisch
Läuft jeden **Montag um 08:00 Uhr** automatisch.

## Setup (einmalig)
Unter **Settings → Secrets → Actions** folgendes eintragen:
- `ANTHROPIC_API_KEY` = dein Anthropic Key
